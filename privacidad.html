Privacidad y tratamiento de datos

Política de privacidad

Actualizada el 18 de octubre de 2026 · YORDING Backup Drive

1. Responsable y finalidad

YORDING Backup Drive es una herramienta de uso administrativo para preparar y conservar copias de seguridad del sistema YORDING. Para consultas sobre esta integración, el contacto es andres.freams@gmail.com.

2. Acceso a la cuenta de Google

La aplicación puede solicitar autorización OAuth para acceder a archivos de Google Drive conforme a los permisos mostrados por Google durante el consentimiento. El acceso se utiliza exclusivamente para depositar, consultar y administrar copias de seguridad en el almacenamiento autorizado por el administrador. La aplicación no ofrece al público acceso a archivos o datos operativos.

3. Qué datos se tratan

Para operar una vez activada, la integración puede tratar metadatos de archivos, identificadores de carpetas, tokens de autorización de Google y contenido de respaldos de la base de datos YORDING. Las copias pueden contener datos operativos y personales que ya forman parte de esa base. Los archivos de Google Drive ajenos al proceso de respaldo no están destinados a ser utilizados por la aplicación.

4. Almacenamiento y proveedores

La arquitectura prevista utiliza GitHub Actions para ejecutar las tareas, Supabase como origen de la base de datos y Google Drive como destino de las copias. Las credenciales se configuran como secretos del entorno de automatización; no se publican en esta página. El nivel de cifrado, la restauración y la política de retención se verificarán antes de poner el flujo automático en funcionamiento.

5. Uso limitado y transferencias

Los datos accesibles mediante las API de Google se utilizan exclusivamente para la funcionalidad de respaldo autorizada por el titular de la cuenta. No se venden ni se usan para publicidad, elaboración de perfiles o entrenamiento de modelos de inteligencia artificial. El tratamiento técnico puede involucrar a los proveedores de infraestructura mencionados, según los servicios que el administrador tenga contratados o habilitados.

6. Conservación y eliminación

Las copias y registros se conservarán según la política de retención que configure el responsable de YORDING. El administrador puede eliminar respaldos, revocar la autorización desde su cuenta Google y solicitar la eliminación o revisión de datos de esta integración mediante el correo de contacto.

7. Derechos y consultas

Las solicitudes relativas al acceso, corrección, eliminación y uso de información podrán dirigirse a andres.freams@gmail.com. Si una solicitud involucra información del sistema principal YORDING, será atendida según las reglas de ese servicio y la normativa aplicable.

8. Cambios

Esta política podrá actualizarse cuando se activen nuevas funciones, proveedores o reglas de conservación. La fecha de actualización se mostrará en esta página.
